## Usage

- **Input Fields**: Enter values into the provided input boxes. Each field is labeled and includes an ARIA `label` for screen readers.
- **Real‑time Calculation**: As you type, the script validates the input and updates the result area instantly.
- **Result Display**: The computed result appears below the inputs, styled for clear visibility.
- **Reset Button**: Click the **Reset** button to clear all inputs and hide the result area.
- **Keyboard Navigation**: Use `Tab` to move between inputs; focus outlines are visible for accessibility.

## Accessibility

- All interactive elements have appropriate ARIA attributes (`aria-label`, `role`).
- Logical tab order ensures keyboard‑only users can navigate the form.
- Focus styles are visible to indicate which element is active.
- Color contrast meets WCAG AA standards.
- Error messages are announced to assistive technologies.
